# Web Interface

The website is plain HTML and CSS. Pages are generated by the C++ server; there is no JavaScript.
Destructive actions use a separate confirmation page.

## Routes

Every route except `/login`, `/setup` and `/static/style.css` requires a logged-in session.
All `POST` routes also require a valid CSRF token (`csrf` form field).

| Method | Path | Purpose |
|---|---|---|
| GET/POST | `/setup` | First-time Super Admin creation (only while no admin exists) |
| GET/POST | `/login` | Login |
| POST | `/logout` | Logout |
| GET | `/` | Dashboard |
| GET | `/books`, `/books/new`, `/books/edit?id=`, `/books/delete?id=` | Book list/search, forms, delete confirmation |
| POST | `/books/add`, `/books/update`, `/books/delete` | Book changes |
| GET | `/members`, `/members/new`, `/members/edit?id=`, `/members/view?id=` | Member list/search, forms, details + issue history |
| POST | `/members/add`, `/members/update` | Member changes |
| GET | `/issues?view=active\|overdue\|completed\|fines`, `/issues/new` | Issue lists and issue form |
| POST | `/issues/new`, `/issues/return`, `/issues/payfine` | Issue actions |
| GET | `/reports?type=inventory\|members\|issued\|returned\|overdue\|fines\|statistics` | Reports |
| GET | `/history?type=` | Activity history (optional filter) |
| GET | `/account` · POST `/account/profile`, `/account/password` | Own account |
| GET/POST | `/admin`, `/admin/create`, `/admin/toggle`, `/admin/reset`, `/admin/settings` | **Super Admin only** |
| GET | `/static/style.css` | Stylesheet |

## Security measures

| Threat | Measure |
|---|---|
| Stolen / guessed passwords | PBKDF2-HMAC-SHA256 hashes, strength rules, lock-out for 30 s after 5 failed logins |
| Session theft | 256-bit random token, `HttpOnly` + `SameSite=Strict` cookie, 2 h idle expiry, new token on every login |
| CSRF | Per-session token in every form, `Origin` header check, `SameSite=Strict` |
| XSS | All dynamic data passes through `html::esc()`; CSP `default-src 'self'` (no inline scripts or styles) |
| Clickjacking | `X-Frame-Options: DENY`, `frame-ancestors 'none'` |
| Privilege escalation | `/admin*` blocked for non-Super Admins in `WebApp::handle` *and* again in `AdminManager` |
| Oversized requests | Header limit 32 KB, body limit 1 MB, 10 s socket timeouts |
| Remote access | Listens on `127.0.0.1` by default |

The server uses plain HTTP. For access from other computers put it behind an HTTPS reverse proxy.
