# Changelog

## 1.0.0

- Core library in C++17: books, members, issues, fines, transaction history, administrators and roles.
- Website user interface (HTML + CSS) served by a small built-in C++ HTTP server.
- Console (menu-driven) user interface sharing the same core classes and data files.
- PBKDF2-HMAC-SHA256 password hashing, CSRF protection, session cookies, HTML escaping.
- Automated tests for the core (173 checks) and the website layer (56 checks).
